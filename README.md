# 🪳 Cockroach Smash Game

[![GitHub Pages](https://img.shields.io/badge/Play%20Now-GitHub%20Pages-brightgreen)](https://iahjhe.github.io/Ambas-finalact1-killthecockroaches/)
[![PWA](https://img.shields.io/badge/PWA-Enabled-blue)](https://iahjhe.github.io/Ambas-finalact1-killthecockroaches/)

A fun Progressive Web App (PWA) game where you smash cockroaches before they escape! Built with HTML5, CSS3, and JavaScript.


## Features
- 🕹️ Addictive smash gameplay
- ⚡ Progressive Web App (installable)
- 📱 Responsive design (works on mobile/desktop)
- 🔊 Sound effects and background music
- 🏆 Score tracking and difficulty levels
- 🔌 Offline play capability

## How to Play
1. Click START GAME
2. Tap/click on cockroaches to smash them
3. Earn higher scores with quick combos
4. Watch out - they get faster over time!

## Installation
**Web Version:**  
Simply visit: [Play Now](https://iahjhe.github.io/Ambas-finalact1-killthecockroaches/)

**PWA Installation:**  
1. Open in Chrome/Edge on desktop or mobile
2. Click the "📲 INSTALL APP" button
3. Enjoy fullscreen gameplay!

## Technologies Used
- HTML5
- CSS3 (Animations, Flexbox)
- JavaScript (Game Logic)
- Service Workers (Offline Functionality)
- Web Manifest (PWA Features)
